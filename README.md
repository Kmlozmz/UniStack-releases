# UniStack — releases

Aquí encuentras las versiones publicadas de **UniStack**: las etiquetas y los APK que descarga la
propia aplicación cuando busca actualizaciones.

## Descargar

En [Releases](../../releases) está la última versión. Descarga el `.apk` y ábrelo en el móvil.
Android pedirá permiso para instalar desde esta app la primera vez.

Las versiones con sufijo (`-alpha`, `-beta`) van marcadas como preestreno: son para probar, y
pueden traer fallos.

## Notas

- Requiere Android 8 o superior.
